# CORE website

A small, static landing page for CORE (Combat Operations: Rival Empires). It uses original game interface and ship images copied into `assets/` so it can be uploaded as a self-contained site.

## Publish

Upload the contents of this repository to the web root for the domain. The site has no build step, server runtime, external fonts, trackers, or third-party requests. `index.html` is the entry page.

All artwork is sourced from the CORE game project. The page identifies CORE as a free sci-fi game and contains no purchase or payment content.
