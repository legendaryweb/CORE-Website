# CORE website

A standalone, static landing page for CORE (Combat Operations: Rival Empires). The site uses the game's in-game captures, interface nameplate, and ship renders. It presents CORE as a free sci-fi fleet command game and lists a target release date of **30 November 2026**.

## Publish

Upload the contents of this repository to the web root for the domain. `index.html` is the entry page. No build step, application server, third-party fonts, analytics, or external assets are required.

## Artwork

All images in `assets/` are copied from the CORE game project. In-game screenshots show the fleet lobby and tactical arena; the separate renders show the Ivanguard-7, Harrow, and Wraith hulls.
